# Lineup Command Center

A phone-first web app that scans every Sleeper league you're in and lists what needs fixing before kickoff: starters who are Out, on bye, Doubtful or Questionable, empty slots, healthy players stuck in IR, and better lineups based on each league's own scoring.

It runs entirely in the browser against Sleeper's public, read-only API. No login, no server.

## Use it
Open the GitHub Pages URL on your phone, then Share → Add to Home Screen.

## Files
- `index.html` — the whole app (HTML, CSS, JS)
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — home-screen install
- `ROADMAP.md` — how it works and what's next
